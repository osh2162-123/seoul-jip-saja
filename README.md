# 서울 아파트 시세 지도

서울 아파트 단지의 실거래 평당가·1년 변화율·용적률·용도지역·역까지 거리를 지도와 목록으로 보고, 대출 한도·월 상환금을 계산하는 정적 웹앱(PWA)입니다. 서버·로그인·방문 통계가 없고, 입력한 소득 등은 브라우저 밖으로 보내지 않습니다.

> **참고용입니다.** 대출 계산 결과는 2026-10-21 기준 공개 규정·금리로 만든 추정치이며 대출 상담·심사 결과가 아닙니다.

## 데이터 기준
- 실거래: 국토교통부 아파트 매매 실거래가, 계약 2021-11 ~ 2026-10 (2026-10-19 수집)
- 건축물대장: 서울특별시 총괄표제부 2026-09-30 갱신분
- 토지특성: 국토교통부 토지특성정보 2026년 기준
- 배경지도: OpenStreetMap(ODbL), 구 경계 SGIS/vuski(CC BY 4.0)
- 대출 규정·금리: 2026-10-21 정리 (출처는 화면 하단 '규정·금리 출처')

자세한 이용 조건은 `THIRD_PARTY_NOTICES.md` 또는 배포 사이트의 `licenses.html`을 보세요.

## GitHub Pages로 배포
1. 이 폴더의 파일을 저장소 루트에 올립니다.
2. Settings → Pages → Branch: `main` / `(root)`를 선택합니다.
3. 배포 주소에서 열고, 휴대폰에서는 브라우저 메뉴의 '홈 화면에 추가'로 앱처럼 설치합니다.

## 업데이트할 때
- 데이터·규정을 바꾸면 `sw.js`의 `VERSION` 값을 올려야 기존 설치본이 새 파일을 받습니다.
- 공공데이터포털·브이월드 인증키(`key.txt`, `vworld_key.txt`)와 수집 원자료는 저장소에 올리지 않습니다(`.gitignore` 참고).
